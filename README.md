# Разработка модуля импорта товаров в электронный магазин из CSV-файлов с хранением данных в коллекциях в памяти

Вариант 1 «Электроника».

## Описание задания

Разработать ASP.NET MVC-модуль импорта товаров в электронный магазин из CSV-файла с хранением данных в коллекциях в памяти.

Основные требования к модулю:

1. Чтение CSV-файла построчно.
2. Преобразование строк CSV в объекты C#.
3. Валидация данных.
4. Добавление корректных товаров в память приложения.
5. Отображение результата импорта: всего строк, успешно импортировано, количество ошибок, список ошибок с номерами строк.
6. Страница просмотра списка товаров.
7. Отладка, тестирование, Git-репозиторий и отчет по практике.

Вариант 1 «Электроника» расширяет базовую модель товара дополнительными полями: brand (обязательно), warranty_months (целое число от 0 до 60, обязательно), model_number (может быть пустым).

## Запуск

```
dotnet run --project ECommerceCsvImport
```

Пример файла: `/csv/sample_products.csv`
